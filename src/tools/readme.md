> [!NOTE]
> **Tools** are deterministic interfaces to the outside world: APIs, data stores, calculators, search, file operations, and so on.
> 
> The players chooses when to call them based on descriptions you provide, instead of only guessing.
That makes the system more reliable, observable, and controllable, because important steps go through defined functions with clear inputs and outputs.

Players carry intent and collaboration; tools turn that intent into grounded, repeatable interaction with real systems.
